Excel Style Kit

図形とセルの、いつもの書式をひとつに。

Excelのパネルで使う

画面・処理はこのHTTPSサイトから読み込みます。利用時にターミナルやMac内のサーバーを起動する必要はありません。インターネット接続が必要です。

Excel登録用ファイルを保存

開発初版です。空のテスト用ブックで動作を確認してください。

Mac版Excelへの登録

  1. 登録用ファイルを保存します。
  2. Excelを保存して⌘＋Qで終了します。
  3. Finderで⌘＋Shift＋Gを押し、下記のフォルダを開きます。

~/Library/Containers/com.microsoft.Excel/Data/Documents/wef

wefがない場合は、ひとつ上のDocumentsフォルダを開き、⌘＋Shift＋Nで「wef」フォルダを作成します。

保存した登録用ファイルをwefへコピーします。以前このExcelアドインのファイルを置いた場合は、IDが同じ古い登録ファイルを置き換えてください。他のアドインのファイルは残します。

Excelを再起動し、空のブックを開いて「ホーム → アドイン」からExcel Style Kitを選択します。リボンに「Style Kitを開く」が表示された場合は、そこからも開けます。

登録後の使い方（v0.4.0）

Excel上で図形を1個選択し、パネルの色・フォント・文字サイズや登録サイズをクリックします。通常はパネル内で図形を選び直す必要がありません。図形サイズはインチ表記に統一し、リサイズは元の中心位置を保ちます。セルもExcel上で選択して書式を適用できます。

図形の直接選択にはExcelApi 1.19対応版が必要です。図形連携用の補助アドインを登録し、パネルの「図形連携を接続」を押すと、Excelで選択した複数図形へのサイズ反映・整列・等間隔配置が使えます。補助一覧はありません。図形連携用アドインを保存。

設定は端末のアドイン内に保存します。「設定」からJSONを書き出してバックアップしてください。ローカル版から移行する場合は配信元が変わるため、旧版で書き出したJSONを読み込んでください。
