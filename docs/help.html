Excel Style Kit v0.3.0

図形サイズの単位

初期値はcmです。図形タブでcm・mm・インチ・ptから、Excelの「図形の書式」と同じ単位を選んでください。単位変更で登録済みの実寸は変わりません。従来の40mmは4cmと表示します。

プリセットの編集・削除

各プリセットの「編集」「削除」から操作します。削除はパネル内の確認欄で「実行する」を押します。削除のキャンセルや保存失敗時は元の設定を保持します。

図形1個への適用

Excel上で図形を1個選んでからパネルのプリセットを押します。書式タブの適用対象は「図形」と「セル」から選択します。図形が取得できない場合にセルへ適用しません。図形サイズは更新後の寸法も読み戻して確認します。

複数選択と整列

現行のパネル方式では、複数選択した図形全体の取得と適用は未対応です。補助一覧と、それを使う整列・サイズ統一・等間隔配置のボタンは削除しました。整列はExcel標準の「図形の書式 → 配置」を使用してください。

設定の保存

設定は端末内のアドインに保存します。「設定」からJSONを書き出してバックアップしてください。同じ配信先での更新では保存形式を維持します。

動作条件

図形直接選択にはExcelApi 1.19対応版が必要です。文字書式は通常の図形・テキストボックスが対象です。実際のExcel上での受け入れ確認は残っています。
