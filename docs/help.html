Excel Style Kit v0.4.1

図形サイズの単位

Excelの実画面で確認したインチ表記に統一しました。単位選択はありません。従来の40mmは約1.57インチと表示し、登録済みの実寸は変えません。

登録サイズの並び替え

「図形 → 登録したサイズ」の各項目の左にある↑・↓を押すと、1つずつ上下へ移動できます。変更した順序は自動保存され、次回も同じ順で表示します。サイズを適用せずに並び順だけを変えます。

JSONにも順序を保存します。順序を含めて復元する場合は、読み込み方法を「すべて置き換える」にします。「追加・更新」は現在の並び順を維持します。

プリセットの編集・削除

各プリセットの「編集」「削除」から操作します。削除はパネル内の確認欄で「実行する」を押します。削除のキャンセルや保存失敗時は元の設定を保持します。

図形1個への適用

Excel上で図形を1個選んでからパネルのプリセットを押します。書式タブの適用対象は「図形」と「セル」から選択します。図形が取得できない場合にセルへ適用しません。サイズ変更では元の図形の中心位置を維持します。更新後の寸法・位置も読み戻して確認します。

複数選択と整列

図形連携用アドインを登録し、パネルの「図形 → 図形連携を接続」を押します。その後Excel上で1個または複数の図形を選び、登録サイズや整列ボタンをクリックします。完了表示まで選択・シートを切り替えないでください。等間隔配置は3個以上必要です。サイズ統一の基準はExcel内部の選択順序の先頭です。

連携では作業ブックに非表示の「_ExcelStyleKitBridge」シートを追加します。図形をシート中央へ集める処理ではなく、それぞれの中心位置を保ってサイズを変えます。

Macで補助アドインを登録する

  1. ExcelStyleKitNative.xlamを保存し、移動しないフォルダへ置きます。
  2. Excelの「ツール → Excelアドイン」、または「開発 → Excelアドイン」を開きます。
  3. 「参照」または「選択」で保存したファイルを選び、ExcelStyleKitNativeにチェックを入れてOKを押します。
  4. Excelを再起動し、パネルの「図形連携を接続」を押します。

マクロ利用を会社が制限している場合は管理者へ確認してください。ターミナルの起動は不要です。Excelを再起動したらパネルの接続もやり直してください。

設定の保存

設定は端末内のアドインに保存します。「設定」からJSONを書き出してバックアップしてください。同じ配信先での更新では保存形式を維持します。

動作条件

補助アドインなしで図形1個を直接取得する場合はExcelApi 1.19対応版が必要です。文字書式は通常の図形・テキストボックスが対象です。Mac実機で補助アドインの単体・連携処理を確認しました。GitHubへ更新したパネルからの最終確認は、配信後に行ってください。
