Excel Style Kit

書式を登録して、セルや図形に適用するExcelアドインです。

基本操作

セルはExcelで範囲を選択して、プリセットをクリックします。図形は「図形」タブで一覧を更新し、チェックボックスで対象を選びます。

「＋ 登録」で追加、「⋯」で編集・削除できます。「現在の設定を読み取る」はセルの左上または図形1個から読み取ります。

設定の保存

設定は端末のアドイン内に自動保存します。「設定」からJSONを書き出してバックアップしてください。読み込みは同じIDの更新または全件置き換えに対応します。

単位と対象

図形サイズはmm、行高・列幅・文字サイズはptです。列幅はExcel標準の文字数単位とは異なります。サイズ統一は最初にチェックした図形を基準にします。

通常の図形・テキストボックスの文字書式に対応します。グループ内の個別図形、画像内の文字、グラフの文字は対象外です。
